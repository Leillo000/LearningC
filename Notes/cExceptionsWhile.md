# Excepciones

Dentro de C existe una excepción en los ciclos *while*, ya que no podemos hacer lo siguiente:

    while (variable1 == variable2){
        // Instrucciones
    }
Ya que ocurre algo curioso al comparar 2 variables con ==, aun no sé por qué, pero no es muy recomendable, es mejor poner la condición contraria.
