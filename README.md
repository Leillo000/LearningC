## 📖 About This Repository

This repository is my daily practice log for programming in **C/C++**.

The goal here is **not** to master every technical corner of the language (memory models, compiler internals, advanced pointer tricks, etc.). Instead, C/C++ is the tool I chose to **train my logic**: breaking problems down, thinking step by step, and turning ideas into working code.

If a solution is a bit rough or unoptimized, that's fine. What matters is the **thinking process** and the **consistency**.

## ⚙️ How to Compile and Run

To compile any C file, follow the next steps:

- Install any compiler whether from Visual Studio Code or MinGW (a wide suit of tools).
- All enviroments paths will set automatically.
- Load your project into Visual Studio Code and press run (the button is top right).

To install MinGW [click here](https://sourceforge.net/projects/mingw/).


### 🔤 About special characters

To display Spanish accents and the "ñ" without relying on source-file encoding, the program prints characters through their **extended ASCII codes** (for example, `160` for "á" and `164` for "ñ"). This matches the default code page of the **Windows console**. On Linux or macOS terminals these characters may look different or garbled; this does not affect the logic of the exercises.

## 💡 Approach

1. **Understand** the problem before writing any code.
2. **Plan** the logic (on paper or in comments).
3. **Implement** a working solution, even if it's not elegant.
4. **Test** with different inputs, including edge cases.
5. **Reflect** on what could be simpler or clearer.
